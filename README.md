# HelvinFrancis.github.io

Personal portfolio site for **Helvin Francis** — Software Engineer specializing in Microsoft Power Platform, SharePoint, .NET Core, and AI-powered automation.

🔗 Live site: [helvinfrancis.github.io](https://helvinfrancis.github.io)

## About

A single-page portfolio built as one self-contained `index.html` (no build step, no dependencies) covering:

- **Home** — intro, role, and contact/social links
- **Skills & Capabilities** — Power Apps, Power Automate, SharePoint, Data & Analytics, Languages & Frameworks, Leadership
- **AI-Powered Automation** — AI Task Generator (Planner plugin) and AI Risk Generator (PCF control)
- **Certifications** — Microsoft Power Platform credentials
- **Experience** — timeline from Associate Software Developer to Technical Lead at Eyeraise
- **Projects** — client engagements (Schneider Electric, A*STAR, PROCEN, Singapore Telecommunications, Security Bank)
- **Education**
- **Contact** — email, phone, LinkedIn, GitHub

## Tech

- Plain HTML/CSS/JS — no frameworks or build tools
- Google Fonts: Space Grotesk, Inter, JetBrains Mono
- Scroll-based reveal animations and an active-section "flow spine" progress indicator via `IntersectionObserver`
- Fully responsive with a mobile nav toggle

## Running locally

Just open [index.html](index.html) in a browser, or serve the folder with any static server.

## Deployment

Hosted via GitHub Pages directly from this repo's `main` branch.
